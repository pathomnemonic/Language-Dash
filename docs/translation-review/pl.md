## Remaining doubts

- 80 learn / 89 teach: both uczyć; learning is properly 'uczyć się' (reflexive); no clean one-word alternative
- 105 hope: spodziewać (się) really means 'expect'; correct is 'mieć nadzieję' (phrase), no clean one-word verb
- 109 agree, 610 laugh, 612 smile, 613 enjoy, 616 worry, 623 imagine, 700 argue, 776 climb, 839 appear, 841 happen: inherently reflexive (się) verbs listed without się
- 638 realize: uświadomić (sobie); alternative: zrozumieć
- 216 away: daleko duplicates 'far'; 217 up / 218 down: comparatives wyżej/niżej stand in for 'w górę/w dół'
- 653 homework: zadanie (task); correct is 'zadanie domowe'
- 745 owe: zawdzięczać means 'owe gratitude'; for money: być dłużnym
- 714 website: witryna is formal; strona internetowa is more common
- 738 sale: sprzedaż; wyprzedaż if discount sale is meant
- 160 morning: rano is an adverb; ranek/poranek is the noun
- 532 way (path): trasa is 'route'; droga is also fine
